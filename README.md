# resumeanayliserpwioi

A premium ATS Resume Analyzer built with TanStack Start, React, TypeScript, Tailwind, and Gemini API.

## Features
- Dynamic PDF Resume parsing and text extraction.
- Detailed visual dashboard breakdown (Overall ATS scores, keyword match density, formatting, and impact metrics).
- Pill/Tag cloud highlighting Optimized vs Missing keywords.
- Side-by-side Comparative panel (Competitive Strengths vs Actionable Roadmap recommendations).
- Interactive Scan History & Progress timeline.
- Clean PDF Report Download capabilities.
